Frequently Asked Questions

How do I use the case converter?

Simply paste or type your text into the input box, then click one of the conversion buttons — UPPERCASE, lowercase, Title Case, Sentence case, or Toggle case. The converted result appears instantly in the output box, ready to copy with one click. No registration or installation is needed.

What is the difference between Title Case and Sentence case?

Title Case capitalizes the first letter of every word (like 'The Quick Brown Fox'), while Sentence case capitalizes only the first letter of each sentence and leaves the rest lowercase (like 'The quick brown fox'). Title Case is common in headings and titles; Sentence case is typical in paragraphs.

Is my text private when using this tool?

Yes. All text conversion happens locally in your browser using client-side JavaScript. Your text is never uploaded to a server or stored anywhere, so it's safe for confidential drafts, code snippets, and personal writing.

Can I convert text with special characters or other languages?

Yes. The converter uses standard Unicode-aware JavaScript string methods, so it handles accented characters, umlauts, and other supported scripts correctly. Some edge cases with uncommon characters may behave differently than in word processors.
